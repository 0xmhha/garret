# Invitation code wordlist

`words.txt` is the EFF large wordlist for random passphrases
(<https://www.eff.org/files/2016/07/18/eff_large_wordlist.txt>, published in
"EFF's New Wordlists for Random Passphrases", July 2016), with the dice
numbers removed and the four words that contain a hyphen (`drop-down`,
`felt-tip`, `t-shirt`, `yo-yo`) left out, so `-` can separate words. 7,772
words remain.
